# 调查长表采集器（survey_extractor）

把调查机构从旧平台导出的**带文字层 PDF 长表**转成关系行。每个字段都附带
**页码、原文字块和坐标框**，可以追溯到原 PDF 页面。无需 OCR，不做调查权重
或统计分析；不悄悄改字、不推断数字。

- 提取器：`survey_extractor/`（Python + pdfplumber）
- 合成材料：`fixtures/`（ReportLab 生成，可复跑）+ 独立写出的预期 `fixtures/expected/`
- 测试：`tests/`（17 个用例）
- 文档：本文件

```bash
python -m fixtures.make_fixtures out/fixtures     # 重新生成合成 PDF 与布局字典
python -m fixtures.expectations fixtures/expected # 重新生成独立预期
python -m pytest tests/ -q                        # 全部测试
python -m survey_extractor inspect out/fixtures/main.pdf        # 布局证据
python -m survey_extractor extract out/fixtures/main.pdf -o r.json --debug-dir out/debug
python -m survey_extractor explain out/fixtures/main.pdf --record Q17
```

## 支持边界（明确的支持范围）

只处理满足以下条件的 PDF，超出范围会报告而不是猜测：

1. **文字层可提取**：横排、无旋转（`page.rotation == 0`）、字形可提取
   （`upright` 且 `size > 0`）。扫描件/图片型 PDF 不在范围内（不做 OCR）。
2. **表框**：每个表在每页由一个足够大的矩形框给出（宽 ≥100pt、高 ≥30pt），
   表左右界即表框边。一页可有多个表框。
3. **表名**：表框正上方 48pt 内的最近一行文字是表名；更高的文字是页眉，
   表框外的文字（页脚数字、下一表名）一律不是业务值。
4. **表头**：表框上缘到第一条通栏横线（覆盖表宽 ≥90%）之间是表头带，
   有序列名从表头字块横向聚类得到。第一页和续页都必须有完整列标题。
5. **编号列**：默认第 0 列（`--id-column` 可改），编号默认匹配 `Q\d+`
   （`--id-pattern` 可改）。每条业务记录在编号列恰有一个唯一编号。
6. **地区列**：默认列名"地区"（`--region-column` 可改）；没有该列则不启用
   跨行地区解析。
7. **候选行界**：编号列内的短水平线。其他列不保证有横线；通栏横线
   （非表头分隔线）与无法归类的线只记录、不参与行界。
8. **承接标记**：`编号 + （续）/(续)/(continued)`，位于续页表体上缘 60pt 内。

## 坐标约定（公开）

- **页面坐标**：沿用 pdfplumber 约定，原点在每个页面左上角，y 向下，
  输出为 `(x0, top, x1, bottom)`，单位 PDF 点（1/72 英寸）。
- **表内全局纵坐标 gy**：同一表的各页**表体**（表头分隔线以下、表框下缘
  以上）按页序拼接成连续纵坐标：`gy = 页偏移 + (top − 该页表体上缘)`，
  `gy = 0` 即该表第一页表体上缘。识别出的表头/页脚被移除后才做行切分。
- **列水平边界**：页内各列边界 = 相邻完整列标题中心的相邻中点；
  表左右界 = 表框。列宽在页间可变，字段身份由**列名与次序**决定，不由
  x 位置决定。字块跨列边界超过 `col_cross_tol` 即报结构问题
  （`block_crosses_column`）。

## 公开容差与字块归并规则

全部容差集中在 `survey_extractor/config.py`，随每份输出写入 `config` 字段，
可用 CLI 覆盖。默认值：

| 参数 | 默认 | 含义 |
|---|---|---|
| `line_y_tol` | 2.0 | 字符合并成视觉行的纵向中心容差 |
| `char_gap_tol` | 2.0 | 行内字符水平间隙超过则切分字块 |
| `header_cluster_gap` | 4.0 | 表头字块横向聚类间隙 |
| `col_cross_tol` | 1.5 | 字块允许越过列边界的最大量 |
| `boundary_touch_tol` | 1.0 | 行界与字块边缘允许接触的量 |
| `line_x_tol` | 2.0 | 短线归属某列的横向容差 |
| `line_up_tol` | 2.0 | 地区区间端点与行界的对齐容差 |
| `name_max_dist` | 48.0 | 表名距表框上缘最大距离 |
| `full_width_ratio` | 0.9 | 通栏线判定比例 |
| `marker_band` | 60.0 | 承接标记须位于表体上缘该范围内 |
| `max_solutions` | 2000 | 合法解释枚举上限 |

**字块归并**：字符 → 视觉行（纵向中心聚类）→ 行内按 x 排序、间隙超
`char_gap_tol` 切分 → 字块。字块 id 按 `(页码, top, x0)` 排序统一编号，
因此**与 PDF 内部绘字顺序无关**（有测试保证）。

**字段拼接**：同一视觉行内字块按 x 序直接相连；行与行之间以 `\n` 相连。
不增删任何字符；每个字块的来源（页码、坐标框、原文）单独保留在
`sources` 中，最终字符串永远可以拆回来源。

## 从布局证据到业务行

先建立并检查布局证据（`inspect`），再定业务行（`extract`）：

1. **锚点**：编号列中匹配编号正则的字块；重复编号、编号列杂字都是结构问题。
2. **槽位**：相邻编号锚点之间是一个槽位，**须选且只能选一条行界**；
   候选是编号列短横线。候选若穿过任何普通属性列字块/编号/承接标记
   （容差内接触允许）即为非法，非法原因会在 `inspect` 中列出。
3. **跨页接缝**：无承接标记的接缝是**强制行界**；有承接标记（编号等于
   上页最后一个编号）时接缝不断行，以上页最后编号为虚拟锚点，且选中
   行界必须位于**所有**承接标记之下。标记本身不是字段值。
4. **地区区间**：地区列两条短横线夹出连续跨行区间，区间端点必须对齐
   选中行界或表体端点（`line_up_tol`）；区间内所有完整业务行继承同一
   地区值，不会把某一行切半截。地区字块被行界穿过不算问题（行界概念上
   不延伸到地区列）。
5. **一致性约束**：同一列内字块先后不被反转；一个字块最多贡献给一行；
   编号锚点、各列占据区间、地区区间、续页承接共同约束合法行界组合。

### 唯一 / 歧义 / 结构损坏

- **0 个合法解释** → `structural_corruption`，报告具体问题
  （如 `no_candidate_boundary`、`no_legal_interpretation`、
  `unclosed_region_interval`、`block_crosses_column` 等）。
- **1 个合法解释** → `ok`，全部行输出。
- **>1 个合法解释** → `ambiguous`。两种解释只有在**同一批字块归属不同
  业务行**时才算不同——仅在无文字空白里选择不同坐标不算（按归属签名
  去重）；两份解释即使拼出的文本碰巧相同，只要来源归属不同也算歧义。
  任意字块在所有合法解释中归属相同才可交付；有变化的相邻行按变动字块
  连成**隔离组**，每组给出**两份完整可复算的见证**（全部行界坐标 +
  全部字块归属 + 组内各行拼出的字段）。其余可唯一确定的行照常输出；
  隔离组内跨解释不变的字段（如"对象"）也照常给出，只有不唯一的字段
  置空。

### 续页承接与待核实

- 续页接入前表的条件（三者同时满足）：**表名相同、列名次序相同、地区
  延续标记匹配**（前表地区区间开口时，续页地区列第一个事件必须是收口
  横线而非新地区文字）。列宽改变不改变字段身份。
- 没有完整承接证据时：**上页未完范围**（前表最后一条记录）与**下页无
  编号片段**分别列为 `to_verify`，不凭空接到最近记录。
- **空单元格**（`empty: true`）≠ **被隔离**（字段为 `null`）≠
  **待核实/未提供**（`to_verify` 列表）。三者严格区分。

## 输出格式

`extract` 的每条记录：

```json
{
  "row_index": 6, "id": "Q17", "status": "ok",
  "pages": [1, 2], "spans_page_break": true,
  "fields": {
    "备注": {
      "value": "第一部分记录：房屋结构完好\n院落排水需要整修\n杂物堆放已现场清理\n后续电话回访确认",
      "empty": false,
      "sources": [
        {"bid": 25, "page": 1, "bbox": [274.0, 280.27, 410.5, 290.77], "text": "第一部分记录：房屋结构完好"},
        {"bid": 35, "page": 2, "bbox": [284.0, 127.27, 378.5, 137.77], "text": "杂物堆放已现场清理"}
      ]
    }
  }
}
```

记录状态：`ok` / `isolated`（在隔离组中）/ `to_verify`（可能未完）。
表状态：`ok` / `ambiguous` / `structural_corruption`。
`isolations[].witnesses` 给出隔离组的两份完整解释；`to_verify[]` 给出
待核实项及其来源框；`problems[]` 给出结构问题；`ignored_texts[]` 列出
被排除的页眉/页脚/下一表名。

## 入口

- `inspect <pdf>`：布局证据——表框、列中心/边界、锚点、候选行界及其
  合法性及非法原因、地区线/区间、接缝、承接标记、片段、被忽略文字。
- `extract <pdf> [-o out.json] [--debug-dir dir]`：关系行 + 来源见证；
  有表非 `ok` 时退出码为 1。`--debug-dir` 输出**带来源框的调试页**
  （每个表框页一份 PDF：字块按记录着色并标注 bid、选中行界、第二解释
  行界、地区区间、接缝），用于人工核对。
- `explain <pdf> --record Q17 [--table 表名]`：按记录解释——行界位置、
  承接路径、每个字段由哪些字块（页码/坐标/原文）拼成、隔离/待核实原因。

## 合成材料（fixtures/）

`python -m fixtures.make_fixtures out/fixtures` 生成 8 份 PDF 与布局字典：

| 文件 | 覆盖点 |
|---|---|
| `main.pdf` | 两种列宽、页脚数字、重复页头、跨行地区、折行备注、跨页未完行（Q17 备注末半在第 2 页、Q18 从该页中部开始） |
| `draw_order.pdf` | 与 main 视觉布局相同、内部绘字顺序不同 → 结果必须相同 |
| `ambiguous.pdf` | 一段文字落在同一对编号的两条合法候选行界之间 → 歧义见证 |
| `same_text.pdf` | 相同文字的不同来源：两种解释拼出的文本相同仍算歧义 |
| `missing_id.pdf` | 缺编号：无编号可视行 → 隔离，不臆造编号 |
| `region_conflict.pdf` | 地区区间下界穿过行中部 → 结构损坏（与歧义分别报告） |
| `title_mismatch.pdf` | 续页标题不符 → 不承接，两侧列待核实 |
| `three_page.pdf` | 三页连续承接（Q30 备注跨三页，Q31 从第三页中部开始） |

`fixtures/expected/` 中的预期由 `fixtures/expectations.py` **独立**从布局
常量推出（不经过提取器），测试再拿提取结果对照（值精确一致、来源页/
原文一致、坐标框容差 4pt）；`test_expected_files_not_stale` 防止预期漂移。

## 隔离后如何修正输入

采集器不会替你做选择；按报告修正源数据或导出程序后重跑即可：

1. **行界歧义**（`ambiguous`，见证显示某字块可属两行）：源表在两条候选
   行界之间留了归属不明的文字。修正：在导出侧删掉多余的那条短横线，
   或把该文字明确排入某一行的行盒内。重跑后隔离组消失。
2. **缺编号**（表现同上）：给该可视行补上编号列编号，或删除该行的
   分隔短横线使其并入相邻行。
3. **结构损坏**：
   - `no_candidate_boundary`：相邻编号之间缺少可用的短横线（或被字块
     穿过）——补齐行线或移开压线文字；
   - `no_legal_interpretation`（常见于地区区间冲突）：地区列短横线没有
     对齐任何可行行界——把地区区间端点画到行界上；
   - `block_crosses_column`：文字跨列——检查导出列宽或缩小字号；
   - `unexpected_id_text` / `duplicate_id`：编号列杂字/编号重复——修正
     编号列内容；
   - `unclosed_region_interval`：地区区间到表尾未收口——补收口横线。
4. **待核实**（`to_verify`）：若是跨页行被截断，给续页表体上缘加承接
   标记 `编号（续）`，并保证续页表名、列名次序、地区延续一致；否则把
   无编号片段人工归并后重跑。
5. 修正后重新运行 `inspect` 确认证据干净，再 `extract`。
